Пользователю доступны следующие сценарии:
* (СДЕЛАНО) Задать сегодняшнюю дату: указывает дату в формате русской локали
* (СДЕЛАНО) Вывести справку по всем командам
* ~~Вывести справку по конкретной команде~~
* ~~Вывести справку по категории (?)~~
* (СДЕЛАНО) Выйти

* (СДЕЛАНО) Создать артиста: указывает имя и алиас
* (СДЕЛАНО) Подписать артиста: указывает тип контракта и параметр
* Разорвать контракт: 
* (СДЕЛАНО) Вывести список всех артистов: выводит имя, подписан/нет, дату подписания, дату разрыва контракта
* Вывести одного артиста: выводит имя, подписан/нет, дату подписания, дату разрыва контракта, список релизов с номерами
* Добавить релиз: алиас артиста, название, стиль, список номеров треков
* Добавить трек в релиз: алиас артиста, номер релиза, номер трека

* Создать трек: указать название и номер
* Просмотреть список треков: выводит номер, есть/нет музыка, алиас композитора, есть/нет текст, алиас текстовика, записан/нет, алиас исполнителя
* Добавить текст: указать алиас текстовика, тип контракта, параметр, дату
* Добавить музыку: указать алиас композитора, тип контракта, параметр, дату
* Записать: указать алиас исполнителя и дату

* Список платформ
* Опубликовать: алиас платформы, дата
* Количество прослушиваний трека: номер трека, дата начала, дата конца
* Количество прослушиваний релиза: алиас артиста, номер релиза, дата начала, дата конца
* Отозвать релиз: алиас артиста, номер релиза, дата

* Общий доход: дата начала, дата конца
* Общая прибыль: дата начала, дата конца
* Общие роялти: дата начала, дата конца
* Доход за релиз: алиас артиста, номер релиза, дата начала, дата конца
* Роялти за релиз: алиас артиста, номер релиза, дата начала, дата конца
* Роялти артисту: алиас артиста, дата начала, дата конца
* Прибыль за релиз: алиас артиста, номер релиза, дата начала, дата конца

Формы записи команд:
```
команда параметр1 ...
группа - вывод списка сущностей
группа номер/алиас - вывод информации о сущности
группа номер/алиас команда параметр1 ... - выполнение команды над конкретной сущностью
```
